# DiPlay CN

本仓库基于上游 DiPlay `v0.2.10`。桌面名称为 **DiPlay CN**，包名为 `com.shihab.diplay.cn`，可与官方正式版并存。

为兼容的比亚迪安卓车机提供有线及无线 CarPlay，采用 DiAuto 风格界面。

> 这些项目专注于比亚迪汽车。它们可能在其他品牌上运行，但其他品牌不在支持范围内，也没有增加支持或修复其品牌特定兼容性问题的计划。

## CN 优化了什么

每一版改动都记录在 **[CN 优化日志](docs/CN_OPTIMIZATIONS.md)**：什么时间、改了什么、为什么改。当前基于官方 `v0.2.10`。

- 仪表盘四种显示：只地图、只官方转向卡、地图+官方玻璃卡、地图+可挪自定义卡（左右/上下按 2% 步进，直行也显示）。
- （已并入官方 0.2.10）主屏幕浮动地图卡与仪表盘的同步开关，源自本仓库的 PR #133。
- 媒体/导航音频流选择 0–20，并保留更早版本保存过的导航声道设置。
- 车机语言不支持时默认简体中文；AirPlay 已连接后跳过无线切换看门狗，避免误重连。

0.2.10 为公开预览版，未经 Apple 认证。请安装在车机上，而非 iPhone。无需越狱、转接盒或认证服务器。无线连接支持车载热点或 Wi-Fi Direct（后者需要 Android 10 或更高版本）。

认证使用从公开固件中提取的实验性配件身份，无法保证未来持续可用。部分车机仍可能卡顿或无法应用图标大小设置。应用界面支持英语、简体中文、阿拉伯语、俄语、西班牙语和乌克兰语。源代码、构建说明及许可证随版本提供。
