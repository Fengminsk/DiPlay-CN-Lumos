# DiPlay Lumos 更新记录

本记录按 Lumos 分支的实际提交整理。应用内会把这些改进与继承的 CN 版本记录按日期一起展示。

## Lumos · 采纳 CN 新版修复 — 2026-11-10

- 从 DiPlay CN 0.2.22 分支挑选麦克风分包修复：48 kHz 有线语音改用适合单个链路 MTU 的默认包长。
- 加入 NCM 数据块、AirPlay 控制消息与二进制属性表的输入边界检查；限制 Bonjour 探测回复长度，并避免无线启动时的反向 DNS 查询。

## Lumos · 弹窗与关于页 — 2026-11-10

- 设置弹窗统一使用应用内玻璃界面，修正多层弹窗的显示顺序；关于页并入设置菜单。
- 关于页展示 Lumos 与 CN 的更新记录，按新到旧排列。

## Lumos · 氛围灯与图标 — 2026-11-10

- 合入氛围灯音乐律动、日间和夜间亮度设置，以及应用快捷方式图标更新。

## Lumos · CarPlay 连接与界面 — 2026-11-10

- 将 CarPlay 连接过程移到前台服务，连接成功后自动进入投屏画面；记住上次使用的有线或无线连接方式。
- 调整连接弹窗、全屏过渡和夜间玻璃界面，减少连接后的黑屏与重复弹窗。

## Lumos · ICCOA 连接与设置 — 2026-11-10

- 修复 ICCOA USB 重复授权、连接后画面卡住等问题，并完善 BLE 配对与 Wi-Fi Direct 连接流程。
- 重构首页、搜索与设置页的液态玻璃交互，改进菜单悬浮滚动与弹窗键盘适配。

## Lumos · 双协议接入 — 2026-11-09

- 加入 ICCOA CarLink 模块，让已连接手机按类型进入 CarPlay 或 ICCOA 连接流程。
