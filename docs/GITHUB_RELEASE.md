# DiPlay CN {{VERSION}}

基于官方 DiPlay v0.2.11。包名 `com.shihab.diplay.cn`，可与官方版并存。覆盖安装上一版 CN 即可保留设置。

**下载**

- APK：本 Release 附带的 `DiPlay-cn-{{VERSION}}.apk`（Gitee 同步：https://gitee.com/oneeyear/DiPlay-CN/releases/latest）
- 完整优化记录：[docs/CN_OPTIMIZATIONS.md](https://github.com/serein-morii/DiPlay-CN/blob/main/docs/CN_OPTIMIZATIONS.md)

**本版更新**

- 「小屏导航 · 独立位置」：仪表切小屏时，车标（默认右移 30%）和自定义转向卡（独立大小/位置，拖动即时生效）都落进小窗里，全屏不受影响。
- 仪表盘设置的位置调节全部改为滑动条（车标左右/上下·全屏与小屏、地图大小）；需重连的项松手时才重连一次。
- 小屏车标与小屏转向卡设置合并为一组；小屏位置步进改为 5%（旧设置自动迁移）。
- 检查更新弹出本版更新详情；关于页展示 CN 特性和各版更新日志。
- 转向卡重开/无线切换不再因 iPhone 的「无路线」瞬间把卡片清掉。
- 同步官方 0.2.11，并保留全部 CN 专属功能：自定义转向卡（滑块大小/透明度/昼夜/行程条）、四通道更新、应用内更新、蓝牙延时暂停、开机自启 ADB 修复、简体中文回退。

请安装在车机上，不要安装在 iPhone 上。车机必须允许安装 APK。
