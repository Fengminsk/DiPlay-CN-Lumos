# 仪表盘导航与小屏模式

前提：设置 → BYD 导航 → 「CarPlay 地图上仪表盘」开启，且车机存在仪表投射显示。

## 仪表显示内容

「仪表显示」四选：只地图 / 官方转向卡 / 地图+官方玻璃卡 / **地图+自定义转向卡**（CN 推荐）。

自定义转向卡：

- 位置：全屏与小屏各一套，1% 步进滑条，设置页有位置比例预览。
- 大小 30–95%、透明度 20–100%。
- 图标白色、路名与行程条近白；昼夜玻璃跟随车机。
- 行程信息条：到达时间 · 剩余时长 · 剩余里程（有路线数据才显示）。
- 断线不清卡；**到达终点（终点指示或剩余 0 米后收到 NoRouteSet）自动清卡**。

仪表地图大小有「更小」档（125% 码流）：iPhone 渲染更大画布、仪表缩下来，同屏地图内容更多更细。

## 小屏导航三模式

设置 → BYD 导航 → 「小屏导航 · 独立位置」：**关 / 开 / 自动**（默认关）。开启后可为小屏窗口单独保存车标位置（默认右移 30%）与转向卡位置。

**自动模式判定顺序**：

1. **ADB 读方向盘菜单的仪表导航模式**（`INSTRUMENT_NAVI_TYPE`：3=小屏、4=全屏），与「仅在小屏/全屏显示地图」同一条只读协议，约 1 秒一次；
2. 没有 ADB 时退回 **使用情况访问（Usage Access）** 监听仪表 Activity；设置页会显示当前来源与授权状态。

模式切换会按需重连仪表码流（仅目标模式确实变化时）；打转向灯弹 360 影像暂时盖住地图**不会**触发重连；地图被盖住后以另一种模式回来才会核对重连。

CarPlay 内下滑菜单顶部有「仪表小屏导航」实时状态（小屏中 / 全屏 / 等待识别），自动缺授权时红字提示。
