# 从源码构建

仓库：`git clone git@github.com:serein-morii/DiPlay-CN.git`（或 [Gitee 镜像](https://gitee.com/oneeyear/DiPlay-CN)）。

## 要求

- Android Studio + JDK 25，Android SDK 37，NDK 28.2.13676358
- `local.properties` 指到本机 SDK（例：`sdk.dir=/Users/xxx/Library/Android/sdk`）

## 构建

主应用选 **`mobile`** 模块：

```
./gradlew :mobile:assembleDebug
```

`maphost` 是仪表地图演示应用。详细步骤与 APK 输出路径见仓库 [docs/BUILD.md](https://github.com/serein-morii/DiPlay-CN/blob/main/docs/BUILD.md)。

## 检查（改代码后必跑）

```
./gradlew :shared:testDebugUnitTest :common:testDebugUnitTest \
  :mobile:lintDebug :mobile:assembleDebug
```

CI（Android checks）每次 push 自动跑同样内容；失败会推 `ci/diagnostics-<run>` 分支带日志。

## 自定义与适配

其他车型适配建议从这些入手：

- 仪表 Activity 名与导航模式地址：`ClusterActivityState.kt`、`BydClusterNaviMode.kt`
- 转向卡绘制与位置：`ClusterTurnCardOverlay.kt`、`ClusterTurnCardView.kt`
- 文案：`common/src/main/res/values*/strings.xml`（七个语言都要加）

改完在 Wiki 或 Issue 里分享你的适配点，可以合回 CN 主线。
