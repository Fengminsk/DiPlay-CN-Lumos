# ADB 相关功能

DiPlay 的 ADB 走**车机自己的网络 ADB**（开发者选项里打开「ADB over network / 网络 ADB 调试」，默认端口 5555）。车机会弹一次密钥授权，同意即可。不会解锁 Bootloader、不会改系统分区。

## 开机自启 · ADB 修复（实验）

部分固件把第三方应用的开机广播拦在后台限制里。设置 → 自动连接 → 「开机自启 · ADB 修复」一键执行：

- `appops set <pkg> RUN_ANY_IN_BACKGROUND / RUN_IN_BACKGROUND allow`
- `cmd deviceidle whitelist +<pkg>`

只把 DiPlay 加入系统白名单；比亚迪私有自启管理（若有）仍需在车机设置里手动允许。固件升级后如失效可重跑。

## CarPlay 期间暂停车机蓝牙（默认关）

场景：手机与车机保持免提配对时，来电会同时弹车机蓝牙电话和 CarPlay 电话。开启后 CarPlay 连接期间通过 ADB 暂时关闭车机蓝牙：

- 延时 5/10/15/30 秒可选（默认 10 秒，避免和无线握手竞争）。
- 暂停期间 CarPlay 通话走中控喇叭 + 车机麦克风，不来电双弹窗。
- CarPlay 结束或下次无线握手前自动恢复蓝牙；配对永不改动。
- 取消/断开/异常重启都只恢复「我们关之前是开着的」蓝牙（lease 机制）。

## 小屏导航「自动」

读方向盘菜单的仪表导航模式（`INSTRUMENT_NAVI_TYPE`，只读），详见 [[仪表盘导航与小屏模式]]。

## 仅在小屏/全屏显示地图

官方功能：仪表处于「关/导航时开启」时让 iPhone 停止发送仪表地图，省带宽。同样通过 ADB 每秒读一次模式。

## 授权与回收

- 车机设置 → 开发者选项 → 网络 ADB 打开后，DiPlay 请求连接，车机弹窗允许（可勾选始终允许）。
- 想收回授权：车机开发者选项里撤销 ADB 调试授权或关闭网络 ADB。
- 仪表是独立 CAN 控制器：以上功能都不直接写仪表；曾出现「仪表简易模式」详见 [[常见问题]]。
