# 安装与升级

## 首次安装

1. 停车状态下下载 APK（车机上直接装，不要装到 iPhone）。
2. 车机允许「安装未知应用」后安装。包名 `com.shihab.diplay.cn`，可与官方 DiPlay 并存。
3. 打开 DiPlay CN，按提示授予 蓝牙/附近设备、通知 等权限。

## 升级

- **0.2.10-cn.4 及以后的版本**：同一把固定签名，直接覆盖安装，设置全部保留。应用内「关于 → 检查更新」可一键完成（首次会请求一次「允许安装未知应用」）。
- **0.2.10-cn.3 及更早**：签名各不相同，升级需最后一次卸载重装。
- 应用内更新从 **0.2.10-cn.8** 才有；更老的安装先手动装一次新版 APK。
- 0.2.11～0.2.13 期间更新的用户注意：0.2.14-cn.1 已修复「下载完不弹安装器」（安装权限在同步时丢失），装一次 0.2.14-cn.1+ 即可恢复一键更新。

## 更新通道

设置 → 关于 → 更新通道，四选一：Gitee（默认，国内快）/ GitHub / gh-proxy.com / ghproxy.net。Gitee 通道读取 Gitee 上的 Release，其余通道最终都指向 GitHub 资源。

## 与官方版共存

两个包名不同，互不影响，但同时只应运行一个投屏应用。切换前先断开当前连接。
