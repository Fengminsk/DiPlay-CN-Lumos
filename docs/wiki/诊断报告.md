# 诊断报告

## 导出

设置 → 诊断 → **保存诊断报告**。Android 10+ 通常保存到 `Downloads/DiPlay`；Android 9 用文件选择器。报告是 `.txt`，不会自动上传。

## 报告前先做

- 复现问题并记下发生时间；
- 检查并删除隐私信息（热点密码等）；
- 注明：车型/车机、DiLink/Android/完整固件版本、iPhone 型号/iOS、连接方式（USB/热点/Wi-Fi Direct/同一局域网）、相关设置、复现步骤、预期与实际、故障时间。

## 关键日志行（小屏/仪表问题）

- `Cluster map: ADB navi mode=Small screen navi / Full screen navi / unknown`——ADB 读到的方向盘模式；
- `Cluster map: detected theme=… mapVisible=… smallWindow=…`——Usage Access 认出的仪表状态；
- `Cluster map: map covered; keeping the stream`——360 盖住地图、按设计不重连；
- `instrument switched to small/full window; stream requested=…`——触发/跳过重连的原因。

## 提交

发到 [Issues](https://github.com/serein-morii/DiPlay-CN/issues)（新建或跟到已有同类问题里）。涉及官方上游本身的问题（与 CN 改动无关）可发官方仓库 issue，注明使用的是 CN 版。
